# Changelog

## 1.0.0 — 2026-04-20

### Added
- Document upload (PDF and DOCX) with drag-and-drop support
- AI-powered course generation via Claude API (title, modules, lessons, quizzes)
- Creator flow: upload → generate → review/edit → publish
- Trainee flow: sequential lesson progression with gated access
- Quiz system with multiple-choice questions and scoring
- Trainee progress tracking (lesson completion, quiz scores, overall percentage)
- Course reset for trainees to start over
- Course regeneration for creators
- White-label theming via CSS custom properties
- Mobile-first responsive design
- ATLAS Integration Standard compliance (health/ready endpoints, structured logging, atlas.yml)
- SQLite persistence
- Docker support
