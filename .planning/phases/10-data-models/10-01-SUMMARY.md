## Decisions Made

- **alembic/env.py uses sys.path.insert(0, parent_dir)** so backend package imports (config, models) work without the package being installed
- **render_as_batch=True in both offline and online configure() calls** — SQLite requires batch mode for any ALTER TABLE or DROP COLUMN operations
- **test_data_models.py uses its own module-scoped test_engine fixture** — avoids conftest.py's autouse setup_test_db which imports main.py and sets up the full app
- **psycopg2-binary included in requirements.txt** despite macOS arm64 build failure — production runs on Linux where it builds successfully

## Issues Encountered

**pytest hangs when running test_data_models.py via CLI** — conftest.py imports `from main import app` at module load time. main.py calls `init_db()` and performs DB setup in its lifespan function context which causes a hang in the test environment. This is a pre-existing issue, not caused by this plan. The test logic was verified by running it directly as Python (confirming correct FAIL/PASS behaviour). The pytest hang will be resolved when conftest.py is refactored in a future plan (or when the test runner environment is fixed). Tests will run correctly once conftest.py no longer imports main at module level.
