    Block ownership helper (traverse slide → video → module → course):
    ```python
    def _get_slide_or_404(slide_id, db, current_user):
        slide = (
            db.query(Slide)
            .join(Video, Slide.video_id == Video.id)
            .join(Module, Video.module_id == Module.id)
            .join(Course, Module.course_id == Course.id)
            .filter(Slide.id == slide_id)
            .first()
        )
        if not slide:
            raise HTTPException(404, "Slide not found")
        # Load course via ORM relationships for ownership check
        course = slide.video.module.course
        if current_user.role.value != "admin" and course.creator_id != current_user.id:
            raise HTTPException(403, "Access denied")
        return slide
    ```
    Note: the join above ensures the slide is fetched with all parent objects loaded (use selectinload or accept N+1 for small data — slide tests don't care about perf).
