    Router prefix: /api/courses for the course-scoped routes, /api/modules for resource routes.
    Use two APIRouter instances OR a single router with explicit paths — prefer single router with tag "modules".

    Pydantic schemas to define in the file:
    - ModuleCreate: title (str, required), description (Optional[str]), learning_objectives (Optional[list]), estimated_duration_minutes (Optional[int]), unlock_rule (Optional[str] = "after_previous"), status (Optional[str] = "draft")
    - ModuleUpdate: all fields Optional

    Reorder implementation (CRITICAL — no order_index drift):
    ```python
    @router.post("/api/courses/{course_id}/modules/reorder")
    def reorder_modules(course_id: int, body: ReorderRequest, db=..., current_user=...):
        course = _get_course_or_404(course_id, db, current_user)
        # Validate all ids belong to this course in one query
        modules = db.query(Module).filter(
            Module.id.in_(body.module_ids),
            Module.course_id == course_id
        ).all()
        if len(modules) != len(body.module_ids):
            raise HTTPException(400, "Some module IDs do not belong to this course")
        id_to_module = {m.id: m for m in modules}
        for idx, mid in enumerate(body.module_ids):
            id_to_module[mid].order_index = idx
        db.commit()  # single transaction
        return {"message": "Reordered"}
    ```

    Ownership helper:
    ```python
    def _check_course_ownership(course, current_user):
        if current_user.role.value != "admin" and course.creator_id != current_user.id:
            raise HTTPException(403, "Access denied")
    ```
